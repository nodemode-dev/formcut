# Lighting environments

Photographed studio environments (HDRIs) that light the device models, from Poly Haven
(https://polyhaven.com), released under CC0 1.0 (public domain dedication). No attribution is
required; it is given here gladly.

| File | Poly Haven asset | Use |
|---|---|---|
| photo_studio.hdr | studio_small_09 (1k) | White cyclorama with two octabox softboxes: clean product light |
| loft.hdr | photo_studio_loft_hall (1k) | Window daylight in a loft: warm, natural light |
| dark_studio.hdr | studio_small_03 (1k) | Black studio with one umbrella key: dramatic dark product light |

formcut normalises each to a common brightness and caps the brightest light sources before
prefiltering (device_scene.py), so the reflections stay clean.
